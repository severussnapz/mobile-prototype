# Phase: P07 Information Governance — Phase 5

## Confirmation and Write — P07

> 📝 **WRITE PROTOCOL — MANDATORY:** For each requirement, write the IG section to the REQ file **one at a time**. After writing: log `"✅ REQ-{N} IG section written ({M}/{TOTAL} complete). Moving to REQ-{N+1}."` Then discard from working context before processing the next requirement.

### What to Write

Write `## Information Governance (Added by Pipeline 07)` section to each requirement file:

1. `### Lawful Basis` — UK GDPR Article 6/9 basis and rationale
2. `### Data Classification` — table of all personal data with classification
3. `### Data Minimisation` — assessment and outcomes
4. `### Retention and Deletion` — periods and mechanisms
5. `### IG Controls` — list of applied IG controls
6. `### Privacy by Design Check` — checklist result
7. `### DPIA Entry` — reference or new entry for DPIA update

### After Writing

Update `feedback/P07_REVIEW_LIST.md` — mark Written as ✅ for the row.

### No Placeholders

See `no-placeholder-enforcement` skill. Never write TBD, TODO, or N/A without a reason to a REQ file.
