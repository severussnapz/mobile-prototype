## P06 Review List

**Purpose:** Create the per-requirement review list for Clinical Safety phase.

Create `feedback/P06_REVIEW_LIST.md`:

```markdown
# Pipeline 06 Clinical Safety Review List — {PRODUCT_NAME}
**Started:** {DATE} | **CSO:** {Name} | **Scope:** {FULL | REDUCED}

| REQ-ID | Name | Haz IDs | Severity | Likelihood | Risk Rating | Controls | Residual | Written | CSO | Flag |
|--------|------|---------|---------|-----------|------------|---------|---------|---------|-----|------|
| REQ-001 | {name} | ⏳ | | | | | | | | |
```

**Resume rule:** First row with blank Written = resume point.

**CSO column:** ✅ = CSO has reviewed and signed off this row. ⏳ = awaiting CSO review.
